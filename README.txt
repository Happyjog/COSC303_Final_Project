# Dungeon Game

Compile:

g++ main.cpp Dungeon.cpp Entity.cpp Item.cpp presets.cpp -o game


Run:


./game


Controls:

w = move north
a = move west
s = move south
d = move east
q = quit

(Try not to press too many other buttons, it may infinitely loop :(   )
Defeat enemies, collect items, and find the boss room to slay the Boss.
